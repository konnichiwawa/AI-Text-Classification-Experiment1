# 当代人工智能——实验一：文本分类

## 1. 实验简介

本实验完成一个多类别新闻文本分类任务。

实验的主要目标是将新闻文本转换为机器学习模型可以处理的数值特征，并比较不同分类算法在验证集上的分类性能。

实验首先使用 TF-IDF 对新闻文本进行特征表示，然后分别训练 Naive Bayes、Logistic Regression、SVM 和 MLP 等分类模型，并在验证集上比较不同模型的分类效果。

为了避免直接使用测试集进行模型选择，本实验从教师提供的训练数据中进一步划分出验证集，用于比较不同的特征参数、分类模型和 MLP 网络结构。测试集仅在最终模型确定之后用于生成预测结果。

此外，本实验还探索了文本清洗方法、不同 MLP 网络结构以及 N-gram 特征表示对分类性能的影响，并结合实验结果分析模型复杂度、特征容量与泛化性能之间的关系。

---

## 2. 实验目标

本实验主要完成以下任务：

1. 加载并分析训练集和测试集；
2. 从训练集中划分验证集；
3. 使用 TF-IDF 将文本转换为数值特征；
4. 比较不同 TF-IDF 特征维度对分类性能的影响；
5. 比较 Naive Bayes、Logistic Regression、SVM 和 MLP 等分类模型；
6. 探索文本清洗对分类性能的影响；
7. 探索不同 MLP 网络结构对验证集性能的影响；
8. 探索 Unigram 与 Unigram+Bigram 特征表示；
9. 分析 N-gram 特征容量对分类性能的影响；
10. 根据验证集结果选择最终模型；
11. 使用全部训练数据重新训练最终模型；
12. 对测试集进行预测并生成 `prediction.csv`；
13. 对实验结果进行可视化和分析。

划分过程使用 `train_test_split` 完成，其中主要参数为：

## 6. 文本特征表示：TF-IDF

本实验使用 `TfidfVectorizer` 将新闻文本转换为机器学习模型可以处理的数值特征。

TF-IDF 是文本分类任务中常用的文本特征表示方法，其基本思想是综合考虑词语在当前文本中的出现频率以及该词语在整个文本集合中的普遍程度。

简单来说：

- 一个词在当前文本中出现得越频繁，其重要性通常越高；
- 如果一个词在大量文本中都频繁出现，那么它对区分不同类别的作用可能较小；
- TF-IDF 综合考虑词频和逆文档频率，为不同词语分配不同的权重。

本实验没有对文本进行额外的数据增强，而是首先使用原始新闻文本进行 TF-IDF 特征提取。

实验重点探索了 `max_features` 参数，即限制 TF-IDF 最多保留的特征数量。

### 6.1 TF-IDF 参数实验

在保持训练集、验证集划分以及分类模型设置一致的情况下，本实验比较了不同 `max_features` 参数对验证集准确率的影响。

实验结果如下：

| `max_features` | 验证集准确率 |
| ---: | ---: |
| 3000 | 88.53% |
| 5000 | 90.43% |
| 8000 | 91.66% |
| 10000 | 91.52% |

从实验结果可以看出：

1. 当特征数量从 3000 增加到 5000 时，验证集准确率明显提高；
2. 当特征数量增加到 8000 时，取得了本次纯 Unigram TF-IDF 实验中的最高验证集准确率；
3. 当特征数量继续增加到 10000 时，准确率反而略有下降。

因此，在纯 Unigram TF-IDF 特征表示下，本实验测试范围内的较优设置为 `max_features=8000`，并将其作为后续 Naive Bayes、Logistic Regression、SVM 和 MLP 模型比较的统一特征容量。

对应的实验结果图为：

`tfidf_parameter_comparison.png`

该实验说明，TF-IDF 特征数量并不是越多越好。在本实验的数据集上，适当增加特征数量能够提供更多有效的文本信息，但继续增加特征后，模型性能提升有限，甚至可能出现轻微下降。

需要注意的是，后续 N-gram 扩展实验使用了不同的特征表示方式。在 Unigram+Bigram 表示下，进一步将特征容量增加到 `12000` 后取得了更高的验证集准确率。

## 7. 文本清洗实验

除了直接使用原始新闻文本进行特征提取，本实验还探索了简单文本预处理对分类性能的影响。

本实验主要比较了以下几种文本处理方式：

1. 使用原始文本；
2. 去除文本头部信息（header）；
3. 去除文本头部信息和标点符号；
4. 在上述处理基础上进一步去除英文停用词（stopwords）。

所有文本清洗实验均采用相同的训练集、验证集划分、TF-IDF `max_features=5000` 和 SVM 分类模型，以保证不同文本处理方式之间具有可比性。

实验结果如下：

| 文本处理方式 | 验证集准确率 |
| --- | ---: |
| 原始文本 | 90.43% |
| 去除 header | 89.08% |
| 去除 header + 标点 | 89.08% |
| 去除 header + 标点 + stopwords | 89.01% |

从实验结果可以看出，简单的文本清洗并没有提高验证集分类准确率。

与原始文本相比：

- 去除 header 后，准确率由 90.43% 降低到 89.08%；
- 在去除 header 的基础上进一步去除标点符号后，准确率仍为 89.08%；
- 进一步去除英文停用词后，准确率降低到 89.01%。

因此，本实验最终保留原始文本，不额外采用上述文本清洗方法。

这一结果说明，对于本实验使用的新闻文本数据集，原始文本中可能包含一些具有类别区分作用的信息。简单地删除文本中的部分内容并不一定能够提高分类性能，过度清洗反而可能损失对分类任务有帮助的信息。

本实验也说明，文本预处理方法需要通过验证集实验进行判断，而不能仅根据经验认为“清洗越充分，分类效果越好”。

## 8. 分类模型比较

在确定纯 Unigram TF-IDF 特征参数之后，本实验进一步比较不同分类算法在相同实验条件下的分类性能。

为了保证不同模型之间的比较具有公平性，本实验统一采用：

- 相同的训练集和验证集划分；
- 相同的 TF-IDF 特征表示；
- `max_features=8000`；
- 固定随机种子 `random_state=42`。

本实验比较了以下四种分类模型：

1. Naive Bayes；
2. Logistic Regression；
3. SVM；
4. MLP。

实验结果如下：

| 模型 | 验证集准确率 |
| --- | ---: |
| Naive Bayes | 89.82% |
| Logistic Regression | 90.43% |
| SVM | 91.59% |
| MLP | 92.40% |

从实验结果可以看出，四种模型均能够完成新闻文本分类任务，但不同模型之间存在明显的性能差异。

Naive Bayes 的验证集准确率为 89.82%，是四种模型中最低的。

Logistic Regression 的验证集准确率为 90.43%，相比 Naive Bayes 有一定提升，说明 TF-IDF 特征能够为线性分类模型提供较好的类别区分信息。

SVM 的验证集准确率达到 91.59%，进一步优于 Naive Bayes 和 Logistic Regression，说明 SVM 在本实验的高维 TF-IDF 文本特征空间中能够学习较有效的分类边界。

MLP 的验证集准确率达到 92.40%，是本次模型比较中表现最好的模型。

因此，在本实验已经测试的四种分类模型中，MLP 获得了最高的验证集准确率，后续将进一步对 MLP 的网络结构进行实验，以研究模型复杂度对分类性能的影响。

不同分类模型的验证集性能比较图保存为：

## 9. 不同分类模型的分析

### 9.1 Naive Bayes

Naive Bayes 是一种基于概率模型的分类算法，其基本思想是根据不同类别下特征出现的概率进行分类。

Naive Bayes 具有训练速度较快、实现简单等特点，也能够较好地应用于文本分类任务。

本实验中，Naive Bayes 的验证集准确率为 **89.82%**。

虽然 Naive Bayes 能够取得较好的分类效果，但在本实验中，其性能低于 Logistic Regression、SVM 和 MLP。

---

### 9.2 Logistic Regression

Logistic Regression 是一种常用的线性分类模型，可以直接在 TF-IDF 得到的高维特征空间中学习不同类别之间的决策边界。

本实验中，Logistic Regression 的验证集准确率为 **90.43%**。

该结果表明，即使使用相对简单的线性分类模型，TF-IDF 仍然能够提供较好的文本分类信息。

---

### 9.3 SVM

SVM（Support Vector Machine）是一种适合处理高维特征空间分类问题的机器学习算法。

本实验使用线性核函数进行分类，主要参数设置为：

- `kernel="linear"`
- `C=1.0`
- `random_state=42`

SVM 的验证集准确率达到 **91.59%**。

在本实验的 TF-IDF 高维稀疏特征空间中，线性 SVM 表现出较好的分类能力，其准确率高于 Naive Bayes 和 Logistic Regression。

---

### 9.4 MLP

MLP（Multi-Layer Perceptron）是一种前馈神经网络，可以通过隐藏层学习输入特征与类别之间更加复杂的关系。

本实验基础模型使用的 MLP 主要参数为：

- `hidden_layer_sizes=(100,)`
- `max_iter=300`
- `random_state=42`

在纯 Unigram、`max_features=8000` 的统一模型比较实验中，MLP 的验证集准确率达到 **92.40%**，在四种分类模型中取得最高结果。

因此，本实验选择 MLP 作为后续网络结构和特征表示扩展实验的基础模型。

---

### 9.5 模型比较结论

综合四种模型的实验结果：

| 模型 | 验证集准确率 | 排名 |
| --- | ---: | ---: |
| Naive Bayes | 89.82% | 4 |
| Logistic Regression | 90.43% | 3 |
| SVM | 91.59% | 2 |
| MLP | **92.40%** | **1** |

从实验现象来看，SVM 和 Logistic Regression 在高维 TF-IDF 文本特征上都表现出了较好的分类能力，这说明线性模型对于文本分类任务仍然具有较强的实用性。

MLP 在本实验中进一步取得了最高的验证集准确率，因此后续继续比较不同 MLP 隐藏层结构，并进一步研究 N-gram 特征表示和特征容量。

## 10. MLP 网络结构实验

为了进一步研究神经网络结构对分类性能的影响，本实验比较了不同的 MLP 隐藏层结构。

所有实验均保持以下条件不变：

- TF-IDF `max_features=8000`
- `max_iter=300`
- `random_state=42`
- 相同的训练集和验证集划分

本实验比较了以下四种网络结构：

| MLP 结构 | 隐藏层数量 | 总神经元数 | 验证集准确率 |
| --- | ---: | ---: | ---: |
| `(50,)` | 1 | 50 | 92.20% |
| `(100,)` | 1 | 100 | **92.40%** |
| `(200,)` | 1 | 200 | 92.27% |
| `(100,100)` | 2 | 200 | 92.33% |

实验结果表明，增加神经元数量或隐藏层数量并不能保证验证集性能持续提升。

当隐藏层结构从 `(50,)` 增加到 `(100,)` 时，验证集准确率从 **92.20%** 提高到 **92.40%**。

但是继续增加模型规模后：

- `(200,)` 的准确率为 **92.27%**；
- `(100,100)` 的准确率为 **92.33%**。

二者均没有超过 `(100,)` 的 92.40%。

因此，在本实验测试的网络结构中，`hidden_layer_sizes=(100,)` 获得了最高验证集准确率。

该结果表明，在当前数据集和纯 Unigram TF-IDF 特征表示下，单纯增加 MLP 的模型复杂度并没有带来持续的性能提升。

需要说明的是，`(100,)` 是后续 N-gram 特征扩展实验中保持不变的基础网络结构，而不是最终特征表示的唯一选择。

不同 MLP 网络结构的实验结果保存于：

`mlp_tuning_results.csv`

## 11. N-gram 特征表示与特征容量实验

为了进一步探索文本特征表示方式对分类性能的影响，在保持数据划分、MLP 网络结构以及随机种子一致的条件下，本实验比较了 Unigram 与 Unigram + Bigram 两种特征表示，并进一步研究特征容量对 Bigram 特征效果的影响。

实验条件如下：

- 数据划分：与前面实验保持一致；
- TF-IDF：`TfidfVectorizer`；
- MLP：`hidden_layer_sizes=(100,)`；
- `max_iter=300`；
- `random_state=42`。

实验结果如下：

| 特征表示 | `max_features` | MLP结构 | 验证集准确率 |
| --- | ---: | --- | ---: |
| Unigram | 8000 | `(100,)` | 92.40% |
| Unigram + Bigram | 8000 | `(100,)` | 91.72% |
| Unigram + Bigram | 12000 | `(100,)` | **92.47%** |

实验结果表明，在特征数量限制为 8000 时，引入 Bigram 后验证集准确率由 92.40% 降至 91.72%，下降 **0.68 个百分点**。

进一步将特征容量增加到 12000 后，准确率提升至 **92.47%**，略高于原始 Unigram 方案。

这一结果表明，在当前实验设置下，N-gram 特征的效果受到特征容量的影响。由于 `max_features` 会限制最终保留的特征数量，当同时加入 Unigram 和 Bigram 时，两类特征需要竞争有限的特征空间，因此简单增加 Bigram 并不一定能够直接提升分类性能。

当特征容量提高到 12000 后，模型能够保留更多具有区分能力的词和词组特征，最终获得更高的验证集准确率。

本实验进一步说明，文本特征表示的选择需要结合特征容量进行分析，而不能仅根据特征形式的复杂程度判断其效果。

- `ngram_experiment_results.csv`
- `ngram_capacity_results.csv`

对应的可视化结果保存为：

`ngram_capacity_comparison.png`

## 12. MLP 训练过程

在基础 MLP 模型实验中，本实验进一步记录了 MLP 的训练损失变化情况，并绘制训练损失曲线。

该实验采用：

- TF-IDF：`max_features=8000`
- MLP：`hidden_layer_sizes=(100,)`
- `max_iter=300`
- `random_state=42`

本次训练实际进行了 **84 次迭代**，最终训练损失约为 **0.003036**。

训练损失曲线保存为：

`mlp_training_loss.png`

从训练损失曲线可以观察到，模型在训练初期损失下降较快，随着训练进行，损失逐渐降低并趋于稳定，最终在第 84 次迭代停止训练。

需要注意的是，该图表示的是**训练损失（Training Loss）**，反映模型在训练数据上的优化过程，并不是验证集损失。

因此，不能仅根据训练损失曲线判断模型是否存在过拟合。本实验主要结合不同 MLP 网络结构在验证集上的准确率进行模型复杂度和泛化能力分析。

从 MLP 网络结构实验可以看出，继续增加神经元数量或隐藏层数量并没有使验证集准确率持续提高。例如 `(200,)` 和 `(100,100)` 的验证集准确率均低于 `(100,)`。

因此，本实验认为，在当前数据集和纯 Unigram TF-IDF 特征表示下，适当控制 MLP 模型复杂度比单纯增加网络规模更加合理。

需要注意：本节训练损失实验对应的是 **8000 维 Unigram 基础 MLP**，最终提交模型则进一步采用了第 11 节验证效果更好的 `12000` 维 Unigram+Bigram 特征表示。

## 13. 最终模型选择

综合 TF-IDF 参数实验、文本清洗实验、分类模型比较、MLP 网络结构实验以及 N-gram 扩展实验，本实验最终确定以下模型作为最终分类模型。

### 13.1 最终文本特征表示

前期纯 Unigram TF-IDF 参数实验表明，`max_features=8000` 在测试范围内取得较优结果。

在此基础上，N-gram 扩展实验进一步比较了：

- Unigram + `max_features=8000`：92.40%
- Unigram + Bigram + `max_features=8000`：91.72%

## 19. 实验中的关键问题与分析

### 19.1 为什么 SVM 和 Logistic Regression 在文本分类中表现较好？

TF-IDF 将文本转换为高维、稀疏的数值特征。对于这种特征表示，线性分类模型可以直接在高维特征空间中学习不同类别之间的区分边界。

本实验中，Logistic Regression 的验证集准确率为 90.43%，线性 SVM 达到 91.59%，说明两种线性模型都能够较好地利用 TF-IDF 特征完成文本分类。

其中 SVM 的表现略高于 Logistic Regression，说明在线性决策边界的情况下，SVM 对当前数据具有较好的分类能力。

### 19.2 为什么文本清洗没有提高准确率？

本实验分别进行了原始文本、去除标题、去除标点以及进一步去除英文停用词等实验。

结果显示，原始文本准确率为 90.43%，而简单清洗后的准确率下降到 89.08% 或 89.01%。

这说明文本中的标题、标点以及部分常见词汇可能包含对类别判断有帮助的信息。直接删除这些信息并不一定能够提高分类性能。

因此，本实验没有为了“预处理更加复杂”而继续增加清洗步骤，而是根据验证集实验结果保留原始文本。

### 19.3 为什么 MLP 在基础模型比较中取得了更高的准确率？

在相同的数据划分和 8000 维 Unigram TF-IDF 特征表示下，MLP 的验证集准确率达到 92.40%，高于 Naive Bayes、Logistic Regression 和 SVM。

这表明在本实验的数据和参数设置下，MLP 能够学习比简单线性分类器更加灵活的特征组合关系。

不过，MLP 的优势并不意味着网络越复杂越好。进一步的结构实验表明，增加神经元数量或隐藏层数量没有持续提高验证集准确率。

### 19.4 增加 MLP 网络复杂度是否一定有效？

实验结果表明并非如此。

- `(50,)` 的准确率为 92.20%；
- `(100,)` 的准确率为 92.40%；
- `(200,)` 的准确率为 92.27%；
- `(100,100)` 两个隐藏层的准确率为 92.33%。

因此，在当前数据集和 TF-IDF 特征表示下，增加模型复杂度带来的收益有限。

这说明模型复杂度需要与数据规模、特征表示以及泛化能力相匹配。单纯增加神经元数量或隐藏层数量，并不能保证验证集性能继续提高。

### 19.5 N-gram 为什么在不同特征容量下表现不同？

本实验比较了三种设置：

| 特征表示 | 特征容量 | 验证集准确率 |
| --- | ---: | ---: |
| Unigram | 8000 | 92.40% |
| Unigram + Bigram | 8000 | 91.72% |
| Unigram + Bigram | 12000 | **92.47%** |

当特征容量固定为 8000 时，加入 Bigram 后准确率下降了 0.68 个百分点。

一种合理的解释是，在 `max_features=8000` 的限制下，Unigram 和 Bigram 需要共同竞争有限的特征空间。一部分原本具有区分能力的 Unigram 特征可能因此无法被保留。

当特征容量增加到 12000 后，模型可以保留更多 Unigram 和 Bigram 特征，因此验证集准确率提升到 92.47%。

这一结果说明，N-gram 特征的效果不仅取决于特征类型，也受到特征容量的影响。

这里的“特征竞争”属于基于实验现象的合理解释，而不是额外证明的因果关系。

### 19.6 本实验的主要经验

本实验最重要的经验之一是：

> 模型和参数的选择应该由验证集上的实际实验结果决定，而不是预先假设某种更复杂的方法一定更好。

例如：

- 更复杂的文本清洗没有带来提升；
- 纯 Unigram TF-IDF 特征数量增加到一定程度后，准确率不再继续提高；
- MLP 增加网络规模后也没有持续提升；
- Bigram 在固定特征容量下反而降低性能，但增加特征容量后取得了更好的结果。

因此，本实验最终选择的是经过多组受控实验验证后的方案，而不是单纯追求更复杂的模型或更多的参数。

## 20. 实验结论

本实验完成了基于 TF-IDF 文本特征和多种机器学习分类模型的新闻文本分类任务。

首先，通过固定 `random_state=42` 并采用分层方式划分训练集和验证集，建立了稳定、可重复的实验条件。在此基础上，对 TF-IDF 特征数量、文本清洗方式、不同分类模型以及 MLP 网络结构进行了逐步比较。

实验结果表明，在纯 Unigram TF-IDF 实验中，`max_features=8000` 取得了较好的验证集表现。简单的文本清洗没有提高分类准确率，因此最终保留原始文本。

在分类模型比较中，Naive Bayes、Logistic Regression 和线性 SVM 均取得了较好的分类效果，其中 SVM 的验证集准确率达到 91.59%。在统一的 8000 维 Unigram 特征表示下，MLP 达到 92.40%。

进一步比较 MLP 网络结构后发现，增加神经元数量和隐藏层数量并没有带来持续的性能提升，因此采用结构相对简单的单隐藏层 MLP，即 `hidden_layer_sizes=(100,)`。

在此基础上，本实验进一步进行 N-gram 特征表示和特征容量扩展实验。实验发现，在 8000 维特征容量下加入 Bigram 后准确率下降到 91.72%，而将 Unigram + Bigram 的特征容量提高到 12000 后，验证集准确率提升至 92.47%，成为本实验所有测试方案中的最高结果。

因此，最终确定的模型方案为：

**TF-IDF (`max_features=12000`, `ngram_range=(1,2)`) + MLP (`hidden_layer_sizes=(100,)`)**

最终验证集准确率为：

**92.47%**

在确定最终模型后，使用全部 7368 条有标签训练数据重新训练模型，并对 2457 条无标签测试数据进行预测，最终生成：

`prediction.csv`

通过本实验可以看出，在文本分类任务中，合理的特征表示、特征容量和模型结构需要结合具体数据集通过受控实验进行选择。实验中的多个结果也说明，模型复杂度并非越高越好，N-gram 特征的效果也与特征容量有关。
